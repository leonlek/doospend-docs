ปรับปรุงล่าสุด: 8 สิงหาคม 2569 (2026)

หน้าหลัก นโยบายความเป็นส่วนตัว เงื่อนไขการใช้งาน คู่มือใช้งาน
สรุปสั้นๆ: ข้อมูลการเงินของคุณ ไม่ออกจาก iPhone/iPad ของคุณ และ Apple iCloud ส่วนตัวของคุณ เราไม่มี server ที่เก็บ transactions, ยอด, หรือบัญชี ส่วนที่ "ส่งออกไป" มีแค่ภาพ/ข้อความที่คุณกดให้ AI อ่าน — สลิป, สเตทเมนต์บัตร, screenshot ประวัติคำสั่งซื้อ และข้อความ voice (Anthropic ผ่าน Cloudflare Worker) คำขอ AI แนบเพียง "รหัสสุ่ม" เพื่อนับโควตา/กันใช้เกิน ซึ่งไม่ใช่ชื่อ อีเมล หรือ Apple ID และไม่บอกว่าคุณเป็นใคร

1. เราเป็นใคร

DooSpend เป็นแอป iOS ส่วนตัว (independent / indie developer) พัฒนาโดย Apiwat Pengjam ติดต่อได้ที่ apiwat.pe@gmail.com

2. ข้อมูลที่เราเก็บและที่อยู่

ประเภทข้อมูลเก็บที่ไหนหมายเหตุ
รายการรับ-จ่าย ยอด บัญชี หมวด งบ ผ่อน subscription ใน iPhone/iPad ของคุณ + Apple iCloud ส่วนตัวของคุณ เราไม่มี server ที่เก็บข้อมูลการเงินของคุณ ไม่เห็นข้อมูลนี้
สมุด (บัญชีร่วม) + รายการในสมุดนั้น Apple CKShare → iCloud shared database เฉพาะคนที่เจ้าของสมุดเชิญผ่านลิงค์เท่านั้นที่เห็น เจ้าของยุติ share ได้ทันที
รูปสลิป (ตอนคุณกด "ถ่ายสลิป") ใน iPhone/iPad ของคุณ + iCloud ส่วนตัว เก็บถาวรจนกว่าคุณลบ — มี Settings → "พื้นที่ภาพ" ให้ลบกลุ่มได้
ภาพ/ข้อความที่ส่งให้ AI อ่าน — สลิป, สเตทเมนต์บัตร, screenshot ประวัติคำสั่งซื้อ (Shopee/Lazada/ฯลฯ) ส่งผ่าน Cloudflare Worker → Anthropic Claude API (US) ส่งเฉพาะตอนคุณกดใช้ฟีเจอร์นั้น ครั้งเดียวเพื่ออ่าน ไม่เก็บถาวร แนบรหัสสุ่มสำหรับนับโควตา (ไม่ใช่ชื่อ/อีเมล/Apple ID)
เสียงพูด (ตอนกด "พูด") แปลงเป็นข้อความด้วย SFSpeechRecognizer ของ Apple (Apple อาจประมวลผลเสียงบน server ของ Apple) เสียงดิบ ไม่ส่งให้ proxy หรือ Anthropic — มีแต่ข้อความ transcribed ที่ส่งต่อให้ AI การประมวลผลเสียงเป็นไปตามนโยบายของ Apple
การใช้ AI (จำนวนครั้ง/เดือน) นับที่ proxy ของเรา (ผูกกับรหัสสุ่ม) + แสดงผลในเครื่องคุณ ใช้เช็ค quota Free/Pro — โควตาเดียวกันทุกเครื่องที่ใช้ Apple ID เดียวกัน
การซื้อ Pro subscription Apple StoreKit (ไม่ผ่านเรา) Apple จัดการเก็บเงินและเก็บข้อมูลการชำระเงิน ตามนโยบายของ Apple เอง

3. ข้อมูลที่เราไม่เก็บ

  • เราไม่ใช้ analytics / tracking SDK (Google Analytics, Firebase, Facebook SDK, ฯลฯ)
  • เราไม่มี user account / login — ไม่ต้องสมัครก็ใช้ได้
  • เราไม่อ่าน SMS, contacts, location, calendar, health
  • เราไม่ขายข้อมูลให้ third party (เราไม่มีข้อมูลให้ขายอยู่แล้ว)

4. บริการ Third Party ที่เราใช้

4.1 Anthropic Claude (ผ่าน Cloudflare Worker)

เมื่อคุณกดใช้ฟีเจอร์ AI ภาพหรือข้อความต่อไปนี้จะถูกส่งผ่าน Cloudflare Worker (proxy ของเราเอง) ไปยัง Anthropic Claude API เพื่ออ่านยอด ร้านค้า วันที่ และจำแนกหมวด: ภาพสลิป, ภาพ/ข้อความสเตทเมนต์บัตรเครดิต, screenshot ประวัติคำสั่งซื้อ (เช่น Shopee, Lazada, TrueMoney), และข้อความ voice transcript ข้อมูลเหล่านี้อาจมีรายละเอียดการเงิน (ร้านค้า ยอด วันที่) — เราส่งให้ AI อ่านเฉพาะตอนที่คุณสั่งเท่านั้น แอปจะขอความยินยอมจากคุณก่อนส่งข้อมูลให้ AI ในครั้งแรก (แจ้งชัดว่าส่งอะไรและส่งให้ใคร) และคุณปิดหรือถอนความยินยอมได้ทุกเมื่อที่ ตั้งค่า › ข้อมูลของคุณ — เมื่อปิด แอปจะไม่ส่งข้อมูลใด ๆ ให้ AI

  • คำขอแนบ รหัสสุ่ม (random UUID ที่สร้างขึ้นในเครื่องคุณและเก็บใน Keychain) ส่งใน header x-device-id เพื่อใช้นับโควตา AI ต่อเดือนและกันการใช้เกิน · รหัสนี้คงอยู่ข้ามการลบ-ติดตั้งแอปใหม่ แต่ ไม่ใช่ ชื่อ อีเมล หรือ Apple ID และไม่สามารถบอกได้ว่าคุณเป็นใคร นอกจากนี้ยังแนบ tier (free/pro) และเวอร์ชันแอป
  • ตั้งแต่เวอร์ชัน 1.8.2 รหัสนี้เก็บใน iCloud Keychain ทำให้ทุกเครื่องที่ลงชื่อ Apple ID เดียวกันใช้รหัสเดียวกัน — โควตา AI จึงนับรวมกันทั้ง iPhone และ iPad แทนที่จะแยกกันคนละก้อน. เราไม่ได้รับ Apple ID ของคุณ ตัวที่ซิงก์คือ UUID สุ่มเท่านั้น และถ้าคุณปิด iCloud Keychain แอปจะกลับไปใช้รหัสเฉพาะเครื่องนั้น
  • Anthropic ไม่ ได้รับรหัสประจำเครื่องนี้ (proxy ของเราใช้เอง) และระบุใน policy ว่าไม่ใช้ API requests ไปเทรนโมเดล (Anthropic Privacy)
  • Anthropic ประมวลผลคำขอภายใต้ Commercial Terms + นโยบายความเป็นส่วนตัวของ Anthropic ซึ่งให้การคุ้มครองข้อมูลในระดับเดียวกับที่ระบุในนโยบายนี้ — ไม่นำ inputs/outputs ไปเทรนโมเดล และเก็บไว้ชั่วคราวเพื่อตรวจการใช้ในทางที่ผิดเท่านั้นแล้วลบตามกำหนดของ Anthropic
  • Cloudflare Worker proxy ของเราไม่ log ภาพหรือเนื้อหา — บันทึกแค่จำนวนคำขอต่อรหัสประจำเครื่องเพื่อนับโควตา/rate limit

4.2 Apple iCloud + Apple StoreKit

ข้อมูลใน CloudKit database เป็น private database ของคุณเอง ใน Apple ID ของคุณ Apple เก็บแบบเข้ารหัสและไม่อ่าน เราไม่มีสิทธิ์เข้าถึง

4.3 การแชร์สมุด ผ่าน CKShare

เมื่อคุณเชิญคนอื่นเข้าสมุด — Apple's CKShare API จัดการเรื่องการอนุญาตและ sync ระหว่าง iCloud accounts ของผู้เข้าร่วม:

  • ลิงค์เชิญทำงานได้เฉพาะกับ Apple ID ที่ owner allow → คนที่ไม่ได้รับเชิญเปิดลิงค์ไม่ได้
  • ข้อมูลในสมุดที่แชร์อยู่ใน Apple iCloud shared database ของเจ้าของ — Apple จัดการ encryption + access control
  • เราไม่มี server กลางของสมุด — เจ้าของปิด share = ผู้เข้าร่วมเสียสิทธิ์เข้าถึงทันที
  • "เพิ่มโดย: ชื่อ" ในรายการใช้ Apple ID record name ของ Apple — ไม่ใช่อีเมล / เบอร์ของคุณ

5. การลบข้อมูล

  • ลบ transaction รายการเดียว: swipe ในรายการ
  • ลบรูปสลิปกลุ่ม: Settings → "พื้นที่ภาพ" → ตามนโยบายอายุภาพ
  • ลบทุกอย่างในเครื่อง: ลบแอป (delete จาก Home Screen) → จะลบข้อมูลในเครื่องและใน iCloud private database ทั้งหมด

6. เด็กและเยาวชน

DooSpend ออกแบบสำหรับผู้ใหญ่ (อายุ 17+ ตาม App Store rating) แอปไม่เก็บข้อมูลเด็กแยกต่างหาก ถ้าผู้ใช้เด็กใช้แอปนี้ ข้อมูลจะอยู่ในเครื่อง/iCloud ของเด็กตามปกติ

7. การเปลี่ยนนโยบาย

ถ้าเปลี่ยนนโยบาย เราจะอัปเดตวันที่ด้านบนของหน้านี้ การเปลี่ยนแปลงสำคัญ (เช่น เพิ่ม third party ใหม่) จะแจ้งในแอปด้วย
