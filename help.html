คู่มือใช้งาน

ปรับปรุงล่าสุด: 29 พฤษภาคม 2569 (2026)

หน้าหลัก นโยบายความเป็นส่วนตัว เงื่อนไขการใช้งาน คู่มือใช้งาน

เริ่มต้นใช้งาน

  1. ดาวน์โหลด DooSpend จาก App Store
  2. เปิดแอป — ดูตัวอย่างใน onboarding 3-4 หน้า
  3. เพิ่มบัญชีของคุณ (เงินสด, ธนาคาร, บัตรเครดิต) — Settings → กระเป๋าเงิน
  4. เริ่มบันทึก — กดปุ่ม "+" กลาง tab bar หรือใช้ tile ลัดบน Dashboard

4 วิธีบันทึกค่าใช้จ่าย

1. ถ่ายสลิป

กด "ถ่ายสลิป" → กล้องเปิด → ถ่ายสลิป → AI อ่านยอด ร้านค้า วันที่ ให้ → ตรวจสอบ → กดยืนยัน

  • รองรับสลิปโอน, สลิป PromptPay, ใบเสร็จร้านอาหาร ฯลฯ
  • ใช้ Apple Vision อ่านข้อความก่อน → Claude Haiku 4.5 จัดการข้อมูล (cost ถูกกว่า full vision)
  • นับ 1 ครั้ง quota AI

2. เลือกสลิป (จากคลังภาพ)

กด "เลือกสลิป" → modal โผล่ขึ้น 2 ตัวเลือก:

  • สลิปทั่วไป — เลือกได้สูงสุด 10 ใบ AI ช่วยอ่านทีละใบ
  • หน้าจอที่มีหลายรายการ — สำหรับ Shopee/Lazada history หรือ statement ธนาคาร 1 ภาพ AI แตกได้สูงสุด 5 รายการ

3. พิมพ์เร็ว / พูด

พิมพ์หรือพูดสั้นๆ เช่น "กาแฟ 75 บาท สตาร์บัคส์" → AI แยกยอด ร้าน หมวด ให้

เสียงแปลงเป็นข้อความบน iPhone (ไม่ส่งเสียงออกจากเครื่อง) แล้วส่งเฉพาะข้อความให้ AI

4. สแกน QR PromptPay (จดก่อนจ่าย)

กด "สแกนจ่าย" → กล้องสแกน QR → preview ขึ้นโชว์ผู้รับ ยอด heads-up checklist (ตรวจก่อนจ่าย)

  • QR ถูกแสดงในแอป — เปิดแอปธนาคารของคุณเอง สแกนจาก DooSpend หรือบันทึก QR ลงคลังภาพ
  • เราไม่ได้ทำธุรกรรม — คุณยืนยันโอนผ่านแอปธนาคารของคุณ
  • หลังจ่ายเสร็จกด ✓ ใน DooSpend เพื่อบันทึกเป็น transaction

ฟีเจอร์เด่นสำหรับบัตรเครดิต

Best Card Selector

ตอนบันทึกรายการ ถ้ามีบัตร 2+ ใบและตั้ง reward rules → แอปจะ ✨ เด้งบอก "ใช้บัตรนี้ได้ X บาท reward"

วางแผนล้างหนี้ (Avalanche / Snowball)

Settings → "วางแผนล้างหนี้" หรือ Dashboard tile "วางแผนล้างหนี้" ที่จะโผล่เมื่อมีบัตร 2+ ใบยอดค้าง

  • Avalanche — จ่ายดอกเบี้ยสูงสุดก่อน ประหยัดเงินมากสุด
  • Snowball — จ่ายยอดน้อยสุดก่อน ปิดบัตรเร็ว สู้ urge อยากเลิกแผน
  • ตั้งงบจ่ายต่อเดือน → ดู timeline จะหมดเมื่อไหร่

Statement OCR

Account detail → "Import Statement" → upload PDF/รูป statement → AI parse → reconcile กับรายการที่บันทึกแล้ว → เพิ่มที่ขาด

แจ้งเตือนวันครบกำหนด

ระบบ schedule local notification 5 จังหวะอัตโนมัติ (7d/3d/1d/วันครบ/หลัง 1d) ปิด/เปิดได้ใน Settings → "แจ้งเตือนบัตรเครดิต"

Pockets / ร่วมจ่าย (multi-user)

Pocket = บัญชีร่วมสำหรับ tag transactions ที่แบ่งกับครอบครัว / เพื่อน / ทริปกลุ่ม ออกแบบให้ทำงานข้ามเครื่อง — owner เชิญผ่าน iCloud link สมาชิกใหม่กดลิงค์แล้วเห็น Pocket + tx ทั้งหมดในไม่กี่วินาที

สร้าง Pocket + เชิญคนอื่น

  1. tab "ร่วมจ่าย" → "+" → ตั้งชื่อ "ทริปสวนสัตว์" + เลือกไอคอน/สี
  2. tap pocket → menu "..." → "เชิญคนอื่นเข้า Pocket"
  3. UICloudSharingController โผล่ → เลือก Messages / Email / Copy link
  4. ส่งให้เพื่อน — ลิงค์ใช้ได้กับ iPhone/iPad ที่ sign in iCloud

tag transaction เข้า Pocket

  1. เพิ่ม transaction ปกติ (capture แบบไหนก็ได้)
  2. tap chip "ร้านค้า / โน้ต" → sheet เปิด → section "Pocket (บัญชีร่วม)"
  3. เลือก Pocket → ถ้าเป็น tx ที่คนอื่นจ่ายให้เปลี่ยน "ใครจ่าย"
  4. save → tx ปรากฏใน Pocket detail พร้อม badge "เพิ่มโดย: ฉัน/เพื่อน"

Settlement — "ใครติดใคร"

เปิด Pocket detail หลังทริปจบ — settlement card จะโผล่ขึ้นมาเองเมื่อมี 2+ คน contribute โชว์:

  • ใช้รวม / คนละเท่าไหร่ (equal split)
  • รายการโอนขั้นต่ำ "A → B ฿X"
  • Per-person summary "เกิน / ขาด / พอดี"

นำตัวเลข transfer ไป PromptPay / โอนหากันเองตามนั้น — DooSpend ไม่ได้ทำธุรกรรม

ข้อมูลใน Pocket

  • sync ผ่าน iCloud private + shared database
  • เฉพาะคนที่ได้รับเชิญเท่านั้นที่เห็น
  • Owner ปิด share ได้จาก UICloudSharingController

ฟีเจอร์อื่นๆ

ซิงก์ iCloud

ทำงานอัตโนมัติถ้าคุณ sign in iCloud — ข้อมูลตามไปทุกเครื่องที่ใช้ Apple ID เดียวกัน เช็คสถานะใน Settings → ความปลอดภัย & ซิงก์

ดู summary ย้อนหลัง

summary card บน Dashboard มีปุ่ม chevron ซ้าย/ขวา ข้างชื่อเดือน — ดูยอดของเดือนก่อนๆ ได้โดยไม่ต้องเปิดหน้าอื่น

ชื่อร้านแทนที่ (Merchant Alias)

เมื่อ AI อ่านชื่อร้านยาวเกินไป เช่น "STARBUCKS COFFEE COMPANY LIMITED" → คุณเปลี่ยนเป็น "Starbucks" → แอปจำให้ ครั้งหน้าสลิปร้านเดิมจะเปลี่ยนชื่อให้อัตโนมัติ

จัดการรายการ alias ได้ที่ Settings → "ชื่อร้านแทนที่"

พื้นที่ภาพ (ลบรูปสลิปเก่า)

Settings → "พื้นที่ภาพ" → เลือกอายุภาพที่อยากเก็บ (6 เดือน / 12 เดือน / เก็บถาวร) → กดปุ่ม "ลบรูปเก่ากว่า X เดือน" — รายการเงินยังอยู่ครบ ลบเฉพาะรูป

Quick Actions (Home Screen)

กดค้างที่ icon DooSpend บน Home Screen → menu: ถ่ายสลิป, สแกนจ่าย, เพิ่มรายการ, พูด

คำถามที่พบบ่อย

Q: ข้อมูลของฉันปลอดภัยมั้ย?

ปลอดภัย — เก็บใน iPhone/iPad + iCloud private ส่วนตัวของคุณ เราไม่มี server มี่เก็บ transactions ดูรายละเอียดที่ นโยบายความเป็นส่วนตัว

Q: แอปทำงานบน Android มั้ย?

ไม่มีตอนนี้ DooSpend เป็น iOS-only แอป

Q: ถ้าเปลี่ยน iPhone ข้อมูลจะหายมั้ย?

ไม่หาย ถ้าคุณ sign in iCloud — ลง DooSpend บนเครื่องใหม่ → ข้อมูลขึ้นเองภายในไม่กี่วินาที

Q: ใน Pocket — ใครเห็นข้อมูลของฉัน?

เฉพาะคนที่คุณ (หรือ Pocket owner) เชิญผ่าน iCloud link เท่านั้น สมาชิกเห็น tx ทั้งหมดใน Pocket แต่ไม่เห็น tx ส่วนตัวของคุณ (ส่วนตัว = ไม่ tag pocket)

Q: Settlement คำนวณยังไง?

แบ่งเท่าๆ กัน (equal split): ใช้รวม ÷ จำนวนคน = ส่วนแต่ละคนควรจ่าย. ใครจ่ายเกิน → คนอื่นติด, ใครจ่ายขาด → ต้องคืน. แอป auto-match ให้ minimum transfers

Q: AI อ่านสลิปผิด ทำยังไง?

ตรวจที่ pending entry ก่อนยืนยัน — คุณแก้ยอด, ร้านค้า, วันที่ ได้ ถ้าแก้ชื่อร้านบ่อยๆ ครั้งหน้าแอปจะจำให้ผ่าน Merchant Alias

Q: ยกเลิก Pro ยังไง?

iOS Settings → Apple ID (ชื่อคุณบนสุด) → Subscriptions → DooSpend Pro → ยกเลิก ใช้ได้จนครบรอบเดือนที่จ่ายไปแล้ว

Q: ส่ง refund ตรงกับคุณได้มั้ย?

ไม่ได้ — refund ทำผ่าน Apple ที่ reportaproblem.apple.com
